# arma3-wiki MCP server

An MCP (stdio) server that serves the Arma 3 wiki data generated by
[acemod/arma3-wiki](https://github.com/acemod/arma3-wiki) on its `dist` branch,
plus bundled scripting tutorials in `tutorials/`.

The server keeps its own copy of upstream `dist` in `wiki/` (git-ignored). It
downloads it on first start, then refreshes in the background on every start and
every 24 hours while running. The `refresh_wiki` tool forces an update. If a
refresh fails, it keeps serving the cached data.

Works on Windows, Linux and macOS.

## Requirements

- Python 3.10 or newer
- Internet access on first start (to download the wiki data)
- Optional: [git](https://git-scm.com/). If it is on your `PATH` the server keeps a
  shallow git clone; otherwise it downloads a zip of the branch from GitHub instead.

## Install

Linux / macOS:

```bash
git clone https://github.com/ScottTMConnors/arma3-wiki-mcp.git
cd arma3-wiki-mcp
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Windows (PowerShell):

```powershell
git clone https://github.com/ScottTMConnors/arma3-wiki-mcp.git
cd arma3-wiki-mcp
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

No git? Download the repository as a zip from GitHub (**Code → Download ZIP**),
extract it, and run the same commands from the extracted folder.

## Register with an MCP client

The client starts the server itself, so it needs two absolute paths: the venv's
Python and `server.py`. Replace `/path/to/arma3-wiki-mcp` with wherever you put
the repository.

| | Python | Server script |
|---|---|---|
| Linux / macOS | `/path/to/arma3-wiki-mcp/.venv/bin/python` | `/path/to/arma3-wiki-mcp/server.py` |
| Windows | `C:/path/to/arma3-wiki-mcp/.venv/Scripts/python.exe` | `C:/path/to/arma3-wiki-mcp/server.py` |

On Windows, use forward slashes (`C:/...`) or doubled backslashes (`C:\\...`) in
JSON and TOML files.

### Claude Code

```bash
claude mcp add arma3-wiki -- /path/to/arma3-wiki-mcp/.venv/bin/python /path/to/arma3-wiki-mcp/server.py
```

Or add it to a project's `.mcp.json`:

```json
{
  "mcpServers": {
    "arma3-wiki": {
      "command": "/path/to/arma3-wiki-mcp/.venv/bin/python",
      "args": ["/path/to/arma3-wiki-mcp/server.py"]
    }
  }
}
```

### Claude Desktop

Add the same `mcpServers` block to `claude_desktop_config.json`
(Settings → Developer → Edit Config), then restart the app.

### Codex

In `~/.codex/config.toml`:

```toml
[mcp_servers.arma3-wiki]
command = "/path/to/arma3-wiki-mcp/.venv/bin/python"
args = ["/path/to/arma3-wiki-mcp/server.py"]
```

### Other clients

Any client that supports stdio MCP servers works: run the venv's Python with
`server.py` as the only argument.

## Tools

| Tool | Purpose |
|---|---|
| `lookup_command(name)` | Full YAML for an SQF command (syntax, locality, examples) |
| `lookup_event(name, category?)` | Full YAML for an event handler |
| `search(query, kind?, limit?)` | Keyword search over names, groups and text |
| `list_group(group)` | Commands in a wiki group; empty lists all groups |
| `list_tutorials()` / `get_tutorial(name)` | Bundled scripting tutorials |
| `wiki_status()` | Data revision, counts, last refresh |
| `refresh_wiki()` | Fetch upstream now |

## Environment variables

All optional.

| Variable | Default | Purpose |
|---|---|---|
| `ARMA3_WIKI_DATA` | `wiki/` next to `server.py` | Where the wiki data is stored |
| `ARMA3_WIKI_REFRESH_HOURS` | `24` | How often to refresh while running |
| `ARMA3_WIKI_UPSTREAM` | `https://github.com/acemod/arma3-wiki.git` | Data repository (must be on GitHub if git is not installed) |
| `ARMA3_WIKI_BRANCH` | `dist` | Data branch |
